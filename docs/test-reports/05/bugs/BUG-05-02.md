\# BUG-05-02. Пользователь изменяет и удаляет чужую заявку — API возвращает 403 вместо 404



\## Состояние и классификация



\- Статус: Confirmed

\- Severity: S3 Minor

\- Обоснование severity: данные не изменяются, но API раскрывает сам факт существования чужой заявки и её автора сообщением «Изменять может только автор». Нарушает принцип «скрытой недоступной заявки» из AUTH-03.

\- Priority: P2

\- Обоснование priority: устраняется той же правкой видимости, что и BUG-05-01, поэтому может быть закрыт в одном релизе.



\## Версия и окружение



\- Продукт: monolith/buggy

\- SHA: e78926a48c633bbe5ef66364f4c79db417ea55d0

\- Адрес среды: http://localhost:8151

\- API-клиент: PowerShell 7, Invoke-WebRequest

\- Дата воспроизведения: 2026-10-09



\## Требование и риск



\- Требование: AUTH-03

\- Ожидаемое правило: «Просмотр чужой недоступной заявки, комментариев и \*\*действия над ней\*\* возвращают 404».

\- Пользовательский риск: userB по коду ответа узнаёт, что чужая заявка существует и что она принадлежит другому автору.

\- Технический риск: перед проверкой прав выполняется проверка авторства, но не выполняется проверка видимости.



\## Предусловия



1\. Среда monolith/buggy запущена и готова (GET /health/ready → ready).

2\. userA (`p05-buggy-a@example.test`) имеет созданную заявку ticket\_id = 6eb337d0-....

3\. userB (`p05-buggy-b@example.test`) имеет активный токен.

4\. Присвоен X-Request-ID для связи с журналом (опционально).

\## Шаги и фактические результаты



| № | Действие | Ожидаемый результат шага | Фактический результат |

|---:|---|---|---|

\## Итоговый ожидаемый результат



Для userB на любую чужую заявку API отвечает \*\*404\*\* и телом «не найдено». Данные заявки остаются неизменными.



\## Итоговый фактический результат



API возвращает \*\*403\*\* с сообщением «Изменять может только автор». Это раскрывает факт существования чужой заявки и её принадлежность другому пользователю. Данные не изменяются.



\## Воспроизводимость



1/1 для PATCH и DELETE. Симптом стабилен, не зависит от содержимого title (проверено с `"Попытка изменить"` и с `"ABC"`).



\## Состояние данных после операции



Инвариант сохранён: title = «P05 заявка A», status = new. Ни PATCH, ни DELETE не изменили заявку.
