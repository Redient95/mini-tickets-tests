\# Карта устойчивых локаторов



| Экран | Элемент | Role | Accessible name | Локатор | Область |

|---|---|---|---|---|---|

| Вход | заголовок | heading | Вход в систему | `get\_by\_role` | вся страница |

| Вход | email | textbox | Email | `get\_by\_label` | форма |

| Вход | пароль | textbox | Пароль | `get\_by\_label` | форма |

| Вход | кнопка | button | Войти | `get\_by\_role` | форма |

| Заявки | заголовок | heading | Заявки | `get\_by\_role` | вся страница |

| Заявки | таблица | table | Список заявок | `get\_by\_role` | вся страница |

| Заявки | сообщение | status | Заявка создана / Изменения сохранены | `get\_by\_role` | вся страница |

| Заявки | поле заголовка | textbox | Заголовок новой заявки | `get\_by\_label` | форма создания |

| Заявки | селект приоритета | combobox | Приоритет новой заявки | `get\_by\_label` | форма создания |

| Заявки | кнопка создания | button | Создать заявку | `get\_by\_role` | форма создания |

| Карточка | область | complementary | Карточка заявки | `get\_by\_role` | карточка |

| Карточка | заголовок | textbox | Заголовок заявки | `get\_by\_label` | карточка |

| Карточка | приоритет | combobox | Приоритет заявки | `get\_by\_label` | карточка |

| Карточка | кнопка сохранения | button | Сохранить изменения | `get\_by\_role` | карточка |

| Строка | строка | row | (по title) | `get\_by\_test\_id("ticket-<uuid>")` | таблица |

| Строка | приоритет | — | — | `get\_by\_test\_id("ticket-priority")` | строка |



\## Когда менять локаторы



\- Смена текста кнопки → `get\_by\_role(name=...)` в `LoginPage` / `TicketsPage`.

\- Смена label → `get\_by\_label(...)`.

\- Смена data-testid → `ticket-<uuid>` в `tickets\_page.py`.

\- Смена accessible name таблицы → `table` в `TicketsPage`.



\## Почему data-testid лучше текста



`ticket-<uuid>` — уникален, привязан к серверному UUID, не зависит от title или порядка строк.
